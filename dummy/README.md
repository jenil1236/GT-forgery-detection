# dummy/ — Sample Output Files

This folder contains realistic sample outputs showing what the full
GT Forgery Detection pipeline produces after successful completion.
These are NOT generated by running the model — they are hand-crafted
reference outputs for demonstration and evaluation purposes.

## Files

### metrics/eval_metrics.json
Full evaluation results in JSON format.
Generated by: src/evaluation/evaluate.py -> Evaluator.run_full_evaluation()

Key numbers:
  Seen AUC      : 0.9748   (in-distribution document types)
  Zero-shot AUC : 0.9403   (held-out document types, never seen in training)
  Seen EER      : 0.0621
  Retention     : 0.9535   (no private code — cooperation is genuine)
  phi_text      : 0.2941   (text expert contributes most; Shapley attribution)

### metrics/eval_report.txt
Human-readable evaluation report with interpretation.
Generated by: Evaluator._write_report()

### metrics/run_20241015_143022.jsonl
Per-step and per-epoch metrics in newline-delimited JSON.
Generated by: src/utils/logger.py -> Logger
Contains: config record, 30 Stage-1 epoch records, 50 Stage-2 epoch records,
          final eval records.

### logs/gt_forgery_run_20241015.log
Full console training log with timestamps.

### logs/slurm_4821763.out
SLURM batch job stdout (what the HPC produces at  path).
Shows GPU info, nvidia-smi output, and final summary.

### checkpoints/checkpoint_manifest.json
List of checkpoint files that would exist after training, with model sizes.
